# 马师傅·文案手艺（自媒体改稿层） — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 带货话术、产品详情页、销售转化、获客（走 pain-point-converter / itch-marketing-engine）
- 选题、结构、开头主结构选择（走 topic-engine / opening-selector / viral-factory）
- “绕过理智”“别有用心”、亏欠恐惧、限时稀缺、差一点+后果逼单
- 小剧场、产品拟人、相声开场、一人分饰多角（呈现形式归编导）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 只取“理”不取“形”：用马师傅的观众视角改句子，不搬他的表演、拟人、谐音、口号和硬引导。
2. 结构和判断归编导；本模块只改句子。开头/标题只在编导产出后补 1–2 个“试用”候选，由编导关卡选。
3. 替换测试：一句话换个对象还成立，就是没说具体的事。
4. 只用底稿里的事实改写；缺素材就标出来问，不编经历、原话、数字。
5. 改完过 VOICE_RULES 终检和广告味检查：卖意图外露、表演、口号化、抖机灵、包装多信息少、站卖家位置；一条稿显眼修辞最多一两处。
6. 口播稿终检后做真人润色（[VOICE_RULES](../../VOICE_RULES.md) 第七节）：极端情绪词、生活化说法、口语化、热梗，词按说话人现场组；语气词和反应句不算显眼修辞。

## 边界与判停

- 底稿缺少改写需要的事实：标“缺素材”并询问，不补编
- 改动会改变人物、数字、因果或限定条件：停，保持底稿原意
- 马师傅候选在编导关卡不过：用编导原版，不硬塞
- 同一条稿显眼修辞已有一两处：不再加（语气词、反应句、极端情绪词按 VOICE_RULES 第七节的用量走，不算在里面）
