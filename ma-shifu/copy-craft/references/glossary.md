# 术语（马师傅用法）
| 术语 | 作者用法 | 位置 |
|---|---|---|
| 生活处境 | 用户过着什么日子，对照“使用场景” | m03#s30 |
| 换句话说 | 换叙述角度：真实反应 / 幻想后果 / 换人 | m09 |
| 手感 | 用的人感到的具体体验，对照“写参数” | m17#s12-s15 |
| 心理感受 | 物理属性在用户心里的结果 | m11#s8 |
| 被动价值 | 不工作时也提供的价值（如颜值） | m11#s13 |
| 意外打断 | 打断熟悉的台词/情节制造记忆点 | m11#s28 |
| 熟悉的帮手+叛逆的结果 | 借熟悉人物/情节开口，结局反常 | m10#s23 |
| 放下身份 | 不端老板/专家身份，站到干活的人那边 | m08#s25 |
| 所以呢 | 顾客看完特性后的追问 | m13#s16 |
| 心价比 | 按情绪价值比较 | m13#s43 |
| 自证陷阱 | 被问贵时自我辩护（“一分钱一分货”） | m13#s36 |
| 递梯子 | 给具体事实，让用户自己得出结论 | m16#s44 |
| 从众效应 | 怕只有我做了这个选择 | m16#s38-s41 |
| 极端案例背书 | 用少数极端场景增强大众信任 | m16#s51-s52 |
| 留白 | 不写到结果，停在开始 | m17#s17-s20 |
| 情绪钩 | 触发核心情绪的瞬间/场景/声音/动作/一句话/故事 | m15#s37 |
| 痛点/爽点/痒点 | 伤口 / 止痛药 / 伤口四周的皮肤 | m20#s107 |
| 预拥有感 | 先替用户彩排拥有后的情景 | m20#s39-s59 |
| 建立标准 | 在顾客心里画一道线 | m12#s35 |
| 带节奏的朋友 | 对照“会说教的老师” | m04#s32 |

> 逐字稿转写错误：“孑点/杨点/养/嫉妒点”=痒点；“孙悦”=孙越；“来芬/莱芬”=徕芬；“坦普尔”=坦博尔。
> 作者把“宜家效应”用于解释观众在心里接话，属类比延伸，本模块不以此为依据。
