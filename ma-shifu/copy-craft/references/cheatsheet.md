# 决策规则速查 — 马师傅·文案手艺（自媒体改稿层）

| 能力 | 一句话规则 |
|---|---|
| 抽象换具体（含五种不写） | 替换测试不过的句子，换成观众做完后具体变了的那件事；没有素材就标缺，不编 |
| 换句话说：真实反应 / 照做后的场景 / 换个人说 | 道理对但没人在乎时，按真实反应→照做后的场景→换个人说的顺序试，场景不夸大，原话须真实 |
| 所以呢：从“我有什么”追到“观众得到什么” | 替观众追问两次“所以呢”，落到他的具体处境；比较对象换成他现在的做法 |
| 口吻：放下身份、别升华、用简单词、做给人看 | 删身份句、命令句、升华句和黑话；说你做过什么，删升华句，停在最后一个具体的事或后果上，不补作业 |
| 开头/标题试用：编导定稿后补 1–2 个候选 | 编导先出开头/标题，再从换个问法、观众的经历、观众不说出口的那句话里补 1–2 个候选，标试用，交编导关卡选；机制解释类默认不补 |
| 人群×处境：说清这条给谁、他正卡在哪 | 写标题开头前列 3 类人×处境各一句认领句，只主攻一类 |
| 对白时机：换成转述会不会变弱 | 换成转述会变弱才用对白；一条最多 1 处（故事型 2 处），一来一回内，说话人具体，后接反应或事实 |
| 熟悉的东西拐个弯（换形态才用） | 只用一句类比或一条正文能讲清理由的反常建议；不演、不谐音，全稿显眼修辞最多一两处 |
| 递梯子：让观众自己得出结论 | 空口句换成可核的数字/记录/做过的事，加熟悉参照，结论留给观众；不编 |
| 情绪定位四问（只用来找选题情绪） | 四问找到“想 A 又怕 B”的核心情绪和观众不太说出口的那句话，交编导用；不写钩子 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
