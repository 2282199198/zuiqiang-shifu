# 示范稿

三份走完流程的示范，用来对照“按步骤做出来是什么样”。示范 1 的素材是自拟的；示范 2 的研究来源是真实的，列在它的证据说明里；示范 3 是默认离线的选题输出，对外部分取自 v2.2 的一次真实输出，用了账号信息（主业旅居、在卖商学院课程）。

| 文件 | 类型 | 走的模块 | 看点 |
|---|---|---|---|
| [01_方法类口播_周会没结论.md](01_方法类口播_周会没结论.md) | 方法类口播 | viral-factory 整稿（Step 1–5）→ copy-craft 改句子 → VOICE_RULES 终检 → 真人润色 | 开头兑现检查拦下一句夸大的“只”；方法在正文讲透（怎么做 / 例子 / 哪里容易错）；初稿结尾“金句 + 作业 + 保证效果”怎么删；极端情绪词心里过了哪三个、为什么选“好家伙，这就完事儿了？” |
| [02_深度稿_午饭后犯困.md](02_深度稿_午饭后犯困.md) | 深度知识口播 | depth-lab（选择门 → 底稿 → 证据 → 成稿）+ 融合爆款表达层 → copy-craft 改句子 → 终检 → 真人润色 | 选择门怎么问；竞争解释怎么比；推断和事实怎么分开写；机制类成稿不带行动段，做法留在底稿；结尾回到开头；“照困不误”“俩实验自己先掐起来了”怎么现场组 |
| [03_选题_南北差异.md](03_选题_南北差异.md) | 选题 | topic-engine（Step 1–5 → 选择门，默认离线） | 四个题怎么配用途（流量、人设、变现）；万古同悲怎么写进描述；账号信息怎么用上；古文拿不准时怎么改（④ 韩愈那句） |

三份都把内部记录摊开了。实际使用时，用户只看到选择门和最终成品，流程记录留在后台。

示范里真人润色用的词，是按那个说话人、那一刻现场组的，换个人换个题就该换，别照抄。

局限：示范稿、改句子判断和终检都出自同一个模型，没有真实播放数据。它说明规则怎么执行，证明不了这样写一定更火。
