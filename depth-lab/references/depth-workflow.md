# 深度工作流

## 一、深度不是什么

- 不是写得长；
- 不是术语多；
- 不是堆数字；
- 不是态度更激烈；
- 不是把任何问题都上升到制度；
- 不是复述参考作者的表达。

可观察的深度是：观众原先只能看到现象，成稿让他看见现象背后的结构，并能用这个结构重新判断现实。

## 二、先确认稀缺增量，再继续下钻

“非常识判断”不等于把通用流程说得更完整。可以用下面的阶梯检查，但不能把它当成每篇必套的固定结构：

```text
表面问题
→ 大多数内容会给出的常见回答
→ 常见回答背后的具体机制
→ 成本、收益、判断权、能力积累或长期后果发生了什么变化
→ 这个变化最终改变观众哪个选择
```

如果结论仍停在“找真实问题、补上下文、设标准、收反馈”，它可能只是中间结论。继续追问最相关的一层：为什么这套流程会让结果分化？它让谁积累了什么、承担了什么、失去了什么选择？哪种东西因此更难被别人直接复制？

合格增量至少属于一种：隐藏机制、非显然区分、决策门槛、失败条件或可迁移判断框架。没有材料支撑时标为推断、未知或待验证，不用抽象词硬填深度。

以 AI 工具题为例：

```text
“别追工具，要做真实任务、建立闭环”只是中间结论
→ 公开工具让初稿更容易获得
→ 私人上下文、删改判断和现场反馈不会随工具公开
→ 持续保留这些反馈，才可能形成别人无法从同一教程直接复制的判断资产
```

这是检查“有没有再深一层”的例子，不是预设所有 AI 选题的答案。

### 二阶深度校准

第一层深度回答“为什么会发生”；二阶深度继续回答“这个机制运行下去，会怎样反过来改变参与者的选择和下一轮结果”。它不是多塞一个理论，而是多解释一层会改变观众判断的后果。

按本题证据选择其中一种即可：

- **激励延续**：谁因此更愿意继续做这件事，为什么坏结果出现后机制仍不会自动停止？
- **规模反馈**：参与者增加以后，供给、价格、注意力、门槛或验收标准如何被反向改变？
- **价值转移**：原来值钱的环节为什么贬值，价值转到哪个更难复制或更接近结果的环节？
- **时间错位**：短期看似有效的动作，为什么会在更长周期暴露成本；或者某种溢价为什么会先于技能本身消失？
- **收益风险分离**：谁先得到确定收益，谁把不确定性、沉没成本或退出困难留到后面承担？

只有二阶影响能得到材料、可观察信号或清楚标注的合理推断支撑时才写。没有证据就缩小结论，并在内部记录“二阶影响：已检查不适用”及缺少的材料或可观察信号；不能无痕省略，也不为显深硬造长期反噬、规模效应或价值迁移。无论选哪一种，最后都要落回一个具体变化：观众因此会多问哪一个问题、改变哪一个判断，或少做哪一步错误投入。

## 三、先写两个以上候选解释

遇到“为什么”时，先列候选，不要立即选第一个：

```text
现象：高端酒店限制外卖上楼
解释1：安全、隐私和责任边界
解释2：员工与配送成本
解释3：餐饮收入和旧商业模型
解释4：楼宇门禁或个别门店政策
```

研究的任务不是挑最戏剧化的答案，而是判断：

- 哪个解释有直接证据；
- 哪个解释只是合理推断；
- 多个解释能否同时成立；
- 哪个解释真正改变观众的判断。

## 四、四个机制镜头

### 1. 利益与风险流

适合加盟、平台、会员、培训、保险、投资、供应链等题目。

追问：

- 谁在什么时候收钱？
- 谁的收益先确定？
- 谁承担固定成本和波动？
- 谁拥有信息和规则制定权？
- 失败后谁最容易退出，谁被沉没成本锁住？

机制写法：

```text
表面承诺 → 收费与控制点 → 成本转移 → 风险暴露 → 退出约束
```

### 2. 模型错配

适合酒店、商场、传统品牌、平台转型、旧行业服务摩擦等题目。

追问：

- 旧规则和固定供给是什么？
- 它原来服务谁，谁付钱，为什么成立？
- 用户、支付者、渠道或替代品发生了什么变化？
- 哪些成本无法同步下降？
- 现在看到的摩擦，是原因还是症状？

机制写法：

```text
旧制度/供给 → 原客群与支付逻辑 → 外部变化 → 收入成本错配 → 应激行为
```

### 3. 制度到个人

适合教育、职场、社区、组织文化和社会观察。

追问：

- 规则奖励什么、惩罚什么？
- 人为了适应规则，形成了什么策略？
- 策略短期为什么有效？
- 长期会塑造什么习惯、关系和心理结果？
- 结构问题是否被错误地归因给个人？

机制写法：

```text
制度规则 → 激励与评价 → 适应策略 → 稳定习惯 → 长期后果
```

### 4. 用户生命周期

适合消费决策、加盟、课程、工具、服务和长期项目。

追问：

- 用户在进入前看见什么承诺？
- 第一次付出的是什么？
- 使用中出现哪些持续成本？
- 失败时为什么会继续投入？
- 想退出时受到什么约束？

机制写法：

```text
看到机会 → 被说服 → 首次投入 → 持续成本 → 追加投入 → 退出与止损
```

### 具体事件的候选追问映射

当输入只有一条可核对的现场记录、对话、截图或个人经历时，可先从事件本身提出候选追问，再决定主镜头：

| 事件级追问 | 对应镜头 | 先找什么 |
|---|---|---|
| 这次是谁先收到钱、节省成本或获得控制权？谁承担了成本和失败风险？ | 利益与风险流 | 收费、权限、成本和退出记录 |
| 事件前后谁的需求、支付者、渠道或替代品变了？哪项旧安排仍然固定？ | 模型错配 | 规则、供给、支付逻辑和变化时间 |
| 现场规则或评价奖励什么？当事人因此采取什么策略？后果有什么信号？ | 制度到个人 | 评价标准、行为记录和长期结果 |
| 当事人看到什么承诺、先付出什么、持续成本在哪里？为什么没有退出？ | 用户生命周期 | 承诺、首次投入、追加投入和退出约束 |

这四组是候选追问，不是四套必做模板。底稿可以比较哪个镜头解释力更强，定稿时只保留一个主镜头，最多一个辅助镜头。

## 五、三环不是凑箭头

合格因果链的相邻两环必须能回答“中间发生了什么”。

不合格：

```text
家长重视成绩 → 孩子长大后空心
```

合格候选：

```text
评价只奖励可量化成绩
→ 学生把外部标准当成行动目标
→ 每次选择都先寻找正确答案
→ 面对没有标准答案的人生时缺少自我判断经验
```

因果链仍需证据。逻辑顺不等于事实已被证明。

每一条因果箭头都要标明证据状态，至少区分为 `[已核验事实]`、`[来源观点]`、`[本轮推断]` 或 `[未知]`。推荐把状态直接写在箭头上，节点本身也在证据账本中标注。例如：

```text
[已核验事实] 评价规则只记录可量化成绩
──[本轮推断]→ [本轮推断] 学生更可能把外部标准当成行动目标
──[未知]→ [未知] 这是否足以解释其成年后的所有选择
```

单个个案只能证明“这个个案发生过”或帮助说明机制，不能单独推出群体因果；相关关系只能说明同时变化或关联，不能直接写成因果；只有前后记录而没有对照、替代解释或其他控制信息，也只能说明时间上的先后，不能直接证明“前者导致后者”。禁止为了补齐三环而虚构样本量、对照组、百分比或效果大小。

底稿可以比较候选镜头，但在确定成稿时只留一个主镜头，最多一个辅助镜头；其余候选应写成被排除、并存或待验证的解释。

### B 型具体事件的口播压缩

当 B 型内容有一条具体事件时，可把论证压缩为：

```text
事件段（已知现场） → 机制段（主镜头的三至五环） → 应对段（核验信号或低风险行动）
```

事件段不能偷渡推断，机制段要逐箭头标状态，应对段不能超出证据能支持的范围。

## 六、时长与压缩规则

时长服务于要讲清的机制，不预设所有深度稿都必须是 90 秒：

- `75—90 秒`：适合一个紧凑机制、一个关键事实和一个对应判断或行动；
- `2—3 分钟`：适合二阶反馈、价值转移、时间差或竞争解释本身就是核心价值的题目；
- 用户已指定时长时以用户要求为准。若时长会迫使核心推理断裂，先说明推荐时长和删减取舍，让用户决定；
- 延长时长不等于增加第二个主题。无论长短，仍只保留一个中心机制，最多一个辅助镜头。

任何时长都优先保留：

1. 非常识判断；
2. 主机制三至五环；
3. 一个最能支撑机制的事实或案例；
4. 一个真正会改变、缩小核心判断或改变行动的竞争解释或边界；不会改变判断的留在内部；
5. 一个对应行动。

优先删除：

- 第二套理论；
- 同义案例；
- 不改变判断的数字；
- 作者背景铺垫；
- 与主机制无关的情绪句。
- 与主问题无关的通用免责声明、常识提醒和自我免责；
- 可以套进大量 AI、成长或职场稿里的抽象总结；
- 只显示作者严谨、但不改变观众判断的边界话；
- 把内部分析标签压缩成三连、四连排比的说明书句子。

## 七、完成检查

- 去掉作者名字后，方法仍然成立吗？
- 去掉所有理论名词后，因果还能用大白话讲清吗？
- 证据是在支撑机制，还是只负责显得专业？
- 反例出现后，核心判断需要缩小到什么范围？
- 观众能否用这套结构观察另一个相似问题？
- 内容是否越过了常见回答和通用流程，至少讲清一项成本、收益、取舍、判断权、能力积累或后果？
- 哪一句是观众不容易从普通同类内容中得到的？如果找不到，继续下钻或缩小题目。
- 哪一句删掉后不损失理解、判断或行动？有就删。
