# 四个按题选择的深度镜头

这些镜头只补 `depth-lab` 的主机制推理，不是四步流水线。每篇只选最能改变判断的一个主镜头；确有必要时最多加一个辅助镜头。内部标签默认不出现在口播里。

## 镜头选择表

| 题目真正卡在哪里 | 选择 | 不要误用 |
|---|---|---|
| 有具体旧解释，但它解释不了一个可观察事实 | 认知缺口与变量保真 | 不强造“大家都以为 A，其实 B” |
| 有明确初判、为检验它而实施的干预、以及真实反馈 | 反馈驱动的判断更新 | 不能用评论分歧或事后想象补成复盘 |
| 单个商业/运营方案要算对象、单位、成立门槛和扩张反馈 | 对象—门槛—规模反馈 | 没有可靠数字时不编精确保本线 |
| 两个或多个真实替代方案要公平比较 | 同目标同口径比较 | 没有可信链条时不硬写长期反噬 |

## 1. 认知缺口与变量保真

适用条件：有具体现象、可追溯材料和一句可检验的旧解释。

内部动作：

1. 写清旧解释本来预测什么。
2. 找到它解释不了的具体观察，定位到对象、时间、单位、质量、责任、成本或协作中的一个缺口。
3. 保留关键变量，把它们映射到本题的人、动作、场景和可观察信号。
4. 写出有条件的机制链，以及在哪些条件下不成立。

没有现象、旧解释或材料时停止本镜头；如果用户正在准备内容且只有宏大主张，先回 `topic-engine` 的问题—知识资产门。生活比喻只能帮助理解，不能替代变量或证据。

## 2. 反馈驱动的判断更新

适用条件：同时存在 `初始判断及理由 → 为检验或改变它而执行的干预 → 可观察反馈`。

内部动作：

1. 固定当时的 v0，不把今天的答案倒灌回去。
2. 说明干预想改变哪个变量、原本预测什么、哪些条件保持不变。
3. 将反馈分为支持、削弱、只推翻一环或没有区分力。
4. 只改写被反馈触及的部分，保留仍成立的判断、未知和下一次可区分验证。

一次同时改很多变量时，只能判为混杂；单条差评只够登记为待验证信号。普通产品/运营问题停在证据准备，不自动转内容入口门；只有明确要做内容且问题—知识资产不清时，才回 `topic-engine`。

## 3. 对象—门槛—规模反馈

适用范围仅限商业、运营、项目、成本、产能或其他有可比数据的题。

内部动作：

1. 先问“在算谁”：用户、付费用户、账户、订单、项目、区域还是交付窗口。
2. 统一分母、时间窗与质量标准，把收入、直接成本、持续成本和约束放到同一个单位。
3. 找成立门槛：什么条件下单位贡献为正、产能不超载或规模能够摊薄固定成本。
4. 再看规模反馈：新增一单、扩大半径或接下第九个项目，会不会改变密度、返工、等待、质量和复购，从而反过来改变门槛。

数据不足时只写关系和所需输入，不编最低订单数、利润率或保本点。若题目其实是在多个真实方案中选一个，转下一个镜头。

## 4. 同目标同口径比较

适用条件：至少两个真实方案在争夺同一个目标，例如人工与 AI、前置仓与社区团购、流程 A 与流程 B。

内部动作：

1. 固定共同目标、观察单位、时间窗与不可接受约束。
2. 用同一把尺比较直接结果，缺项写未知；不同月份、分母和质量定义不能拼成赢家。
3. 只有存在观察证据或清晰中间环节时，才追踪 `直接优势 → 行为/系统反应 → 延迟成本 → 共同目标`。
4. 输出条件性选择、当前不可比，或“尚未发现可靠反转”；不强迫每篇都有赢家。

出现试点数据不等于自动切到“反馈更新”。如果核心仍是 A/B 哪个更合适，或“长期伤信任”有没有证据，本镜头继续负责；只有明确存在事前因果判断、为检验它而实施的干预和反馈，且任务转为更新原判断时，才切到反馈镜头。

## 两个组合例外

- 一个商业方案先需校准单位门槛，随后才与其他真实方案比较：先用对象—门槛镜头，再用同目标比较；它们回答两个不同子问题。
- 单位门槛形成了事前预测，后来真的执行并拿到反馈：才允许接反馈更新；没有真实干预和结果时不能伪造复盘。

## 前台表达纪律

底稿可以使用表格、状态词和方法标签，成稿默认不展示它们。真正进入口播的只有：

- 一个由本题材料支撑的新判断；
- 观众能看见的人、动作、成本、取舍或后果；
- 会改变判断的边界或未知；
- 与机制直接相连的核验问题或行动。

“先明确问题、再补齐材料、设好标准、持续迭代”这类通用流程不能当深度。与主线无关的免责声明、普遍安全提醒和后台自检也不能靠换一种口语说法继续保留。

## 来源与验收

四个镜头来自 `zuiqiang-shifu-depth-expansion-batch2` 的 F03、F04、F05、F08。六项批次方法均经历 Stage 1.5、7 条初始盲测和协调者复核；F04、F08 的近邻错路由被保留记录、回炉修正，并由全新执行者各完成专门回归。这里吸收的是通过后的边界和动作，不复制样本作者口吻或具体结论。
