# 证据与边界规则

## 一、四种状态必须分开

| 状态 | 含义 | 可用写法 |
|---|---|---|
| 已核验事实 | 原始或权威来源直接支持 | “现行标准要求……”并附来源与日期 |
| 来源观点 | 作者、公司、受访者的主张 | “作者认为……”“公司披露……” |
| 本轮推断 | 根据多个事实形成的解释 | “这可能意味着……” |
| 未知 | 证据不足或来源冲突 | “目前无法确认……” |

禁止把后面三类伪装成第一类。

机制链的每一条因果箭头都必须标注上述四种状态之一。个案、相关关系和未经控制的前后记录不得直接升级为因果证明：个案只能说明该个案或提供一个观察入口，相关只能说明关联，前后记录只能说明时间先后。若没有足够证据，应把箭头标为 `[未知]` 或 `[本轮推断]`，降低结论强度，而不是补写证据。

严禁为了让论证看起来完整而编造样本量、对照组、百分比、平均值、效果大小、访谈或案例。用户没有提供、来源没有写明或当前无法核验的数字，一律不能写进事实段。

## 二、证据账本

每个会改变核心判断的事实，都记录：

```text
主张：
状态：已核验事实 / 来源观点 / 本轮推断 / 未知
来源：标题、机构或作者、链接或本地标识
时间：发布或生效时间
范围：地区、样本、品牌、人群或版本
作用：它支撑机制的哪一环
风险：过时、单一来源、样本偏差、口径不明或因果跳跃
```

不改变判断的装饰性数字应删除。

## 三、来源优先级

优先顺序不是绝对，但通常为：

1. 现行官方标准、法规、原始数据和公司正式披露；
2. 原始研究、作者全文、具名访谈和一手案例；
3. 可靠机构的行业报告和专业媒体调查；
4. 二次转载、评论文章和匿名经验；
5. 搜索摘要、无出处截图和传言。

搜索摘要只用于找原文，不能独立承担关键结论。

## 四、时间与版本

- 政策、标准、价格、平台规则和公司状态必须核对当前版本。
- 旧材料可以用来解释历史，但要写明年份和当时范围。
- 不把2019年的经营阈值写成今天仍然适用。
- 新旧标准不一致时，以当前问题对应的生效版本为准，并说明变化。

## 五、竞争解释

每篇至少处理一个对核心判断构成真正挑战的解释。

错误示范：

```text
反方可能不同意，但我还是认为商业模式崩了。
```

合格示范：

```text
限制外卖上楼也可能来自安全、门禁和责任管理；如果酒店允许外部餐食并由员工转送，就不能仅凭“骑手不上楼”推断它在封闭餐饮消费。
```

竞争解释的结果可以是：

- 排除；
- 与主解释同时成立；
- 缩小核心结论；
- 证据不足，保留未知。

## 六、范围词警报

出现以下词时必须核验：

- 所有、任何、一定、必然、普遍、都是、从来、根本；
- 行业都、这一代人、年轻人都、家长都、平台就是；
- 百分比、平均数、倒闭率、成本率、利润率。

不能核验就改为有范围的表达，如“这篇材料中的部分样本”“在某类门店”“可能因素之一”。

## 七、内部严谨不等于成稿免责

事实、推断、未知、竞争解释和适用范围必须在内部底稿中处理，但不因此自动进入口播。

- 与主问题无关的医疗、法律、财务、隐私、专业复核等通用提醒默认删除，不换一种更口语的说法继续保留。
- 上述提醒即使由用户材料或引用文本主动提供，也只算候选材料，不自动算作本轮要求。先服从用户对中心、篇幅和“不展开”的约束，再判断其中有没有会改变本题具体步骤的条件；不得因为原句醒目或完整而照抄。
- 只有某个边界会缩小核心结论、改变观众选择或改变具体步骤时，才紧贴对应判断或行动说明。
- 风险本身就是题目核心时，要讲清“什么信息缺失、哪条规则有例外、因此哪一步转人工”等具体机制，不能只说“注意隐私、谨慎使用、保留人工复核”。
- 用户明确要求证据、风险审计或完整底稿时，按请求单独显示，不混进可直接朗读的成稿。

## 八、材料不足时的正确输出

材料不足不是失败。可以交付：

- 已成立的最小判断；
- 两到三个待验证机制；
- 还需要哪些来源；
- 暂时不能写进成稿的数字和结论；
- 一份不冒充事实的假设版提纲；
- 一个低风险、可观察结果的小实验，以及明确的停止条件。

低证据模式的最小交付顺序是：**最小事实 → 候选假设 → 补证（证据缺口） → 小实验 → 停止条件**。小实验只能用来获得下一步信息，不能把一次试验结果包装成普遍因果结论；若关键输入仍缺失、结果不可观察，或风险已经超过验证价值，应停止扩写并说明原因。
