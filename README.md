## 安装

### 一行命令

```
git clone https://github.com/<你的用户名>/zuiqiang-shifu.git "%USERPROFILE%\.claude\skills\zuiqiang-shifu"
```

Mac 用户：把 `%USERPROFILE%` 换成 `~`

### 手动安装

1. 下载 → 解压
2. 把 `zuiqiang-shifu` 整个文件夹复制到 `.claude/skills/` 目录
3. 重启 Claude Code

详细步骤 → [安装指南](安装指南.md)

## 使用

装好之后，像聊天一样说话：

```
"帮我想个选题"
"帮我看看这个账号怎么定位"
"帮我写一条60秒的口播脚本"
"这条视频开头太慢了，帮我改"
"我的视频数据卡住了，帮我看一下"
```

**不需要记命令、不需要选功能。系统自动识别你的意图，路由到正确集群。**
