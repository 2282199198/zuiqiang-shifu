# 最强师傅 v2.1

这是一个给自媒体创作者使用的内容 Skill。它能从选题一路做到成稿，也能把知识型内容讲得更深，同时尽量减少套话、AI 腔和生硬结尾。v2.1 增加了不可跳步协议：每个模块自己的步骤都要按顺序处理，只有用户明确要求才允许跳过。

## 它能帮你做什么

- 找选题、筛选题、把方向改成更想点开的标题
- 写爆款口播、改开头、重做内容结构
- 写有深度的知识口播，把原因、机制和后续影响讲清楚
- 设计账号定位、IP 故事、涨粉和变现思路
- 在材料不够时先说明缺什么，不拿想象冒充事实
- 深度稿先让你选择讲法、时长，以及是否融合爆款风格；AI 可以推荐，但最终由你决定

## 怎么开始

1. 保留并上传整个 `zuiqiang-shifu-v2` 文件夹，不要只拿出一个 `SKILL.md`。
2. 让你使用的 AI 先读取根目录的 `SKILL.md` 和 `WORKFLOW_PROTOCOL.md`。
3. 直接说你的主题、目标观众和想要的成品；AI 会推荐方向，但最终选题和稿件类型由你决定。

第一次可以直接复制这句话：

> 请先读取 `zuiqiang-shifu-v2/SKILL.md` 和 `zuiqiang-shifu-v2/WORKFLOW_PROTOCOL.md`，然后用最强师傅帮我处理下面的需求。按模块步骤推进，不要跳步；已有信息算对应步骤已完成，不要重复问。先给出判断和推荐理由，把最终选择留给我：＿＿＿＿＿＿。

更详细的步骤和提问例子见 [小白使用说明.md](小白使用说明.md)。

## 在这台电脑的 Codex 里安装

1. 解压 ZIP，只保留一层 `zuiqiang-shifu-v2` 文件夹。
2. 在文件资源管理器地址栏输入 `%USERPROFILE%\.codex\skills`。
3. 把整个 `zuiqiang-shifu-v2` 文件夹复制进去，最终应能直接看到 `%USERPROFILE%\.codex\skills\zuiqiang-shifu-v2\SKILL.md` 和 `%USERPROFILE%\.codex\skills\zuiqiang-shifu-v2\WORKFLOW_PROTOCOL.md`。
4. 新建一个 Codex 任务或重新打开 Codex；已经在运行的旧任务不一定会自动读到新 Skill。
5. 第一次明确说“使用 `zuiqiang-shifu-v2`，先读根 `SKILL.md` 和 `WORKFLOW_PROTOCOL.md`”。

电脑里若还保留旧版 `zuiqiang-shifu`，测试新版时不要只说“用最强师傅”，要明确说“使用 `zuiqiang-shifu-v2`”。如果仍然调用旧版，说明两个版本发生了冲突。

### 给电脑上的其他 Agent 使用

- **同一个 Windows 账号里的 Codex 新任务或子 Agent**：只要已把完整文件夹放进 `%USERPROFILE%\.codex\skills\zuiqiang-shifu-v2`，通常无需给每个任务重复复制；新建任务后明确调用新版即可。
- **其他支持本地 Skill 的 AI 工具**：找到该工具自己的“Skill、知识库或项目文件”入口，把完整 `zuiqiang-shifu-v2` 文件夹放进去，再新建会话或重新加载。不同工具没有统一安装路径，不要直接照搬 Codex 的路径。
- **只支持上传附件的 Agent**：每个项目或对话上传完整 ZIP，让它先读取根 `SKILL.md`、`WORKFLOW_PROTOCOL.md` 和路由到的子模块；只上传一个 `SKILL.md` 会缺少能力和步骤。有些 Agent 不能自动解压 ZIP，这时要上传解压后的完整文件夹；如果它既不能读取文件夹，也不能解压 ZIP，就无法完整使用这个 Skill。

安装完成后先做一次小测试：让 Agent 用一个深度题目工作，但只说“直接写”。新版应先给讲法、时长和是否融合爆款风格的建议，并停下来等你选择；如果它直接交稿，说明它没有完整读到新版规则。

## 使用边界

- Skill 能提高内容判断和成稿质量，但不保证任何视频一定获得播放、转发或成交。
- 需要引用新闻、数据或外部事实时，应先核对来源；材料不足时不编数字、人物动机或结果。
- 规则、参考文件和子模块互相配合，删除文件可能让某些能力失效。
- Skill 能明显加强约束，但不能保证所有不同品牌的 Agent 都百分之百服从；要用下面的小白说明做首次测试。
