# 最强师傅 V3.0

给自媒体创作者用的内容 Skill：从选题一路做到成稿，知识型内容能讲深，尽量少套话、少 AI 腔，结尾不硬收。现在是 V3.0，每一版改了什么见 [CHANGELOG.md](CHANGELOG.md)。

## 它能帮你做什么

- 找选题、筛选题、把方向改成更想点开的标题；选题默认不联网，出 3–5 个，每个写清用途、需求和量级，推荐一个
- 写爆款口播、改开头、重做内容结构
- 写有深度的知识口播，把原因、机制和后续影响讲清楚
- 设计账号定位、IP 故事、涨粉和变现思路
- 在材料不够时先说明缺什么，不拿想象冒充事实
- 成稿不报幕、不堆安全词和免责、不让“不是……而是……”成串，结尾不布置作业，允许有情绪、有脾气
- 口播稿听着像真人在说：会有“这哪儿跟哪啊”这种反应、语气词，情绪最高的地方会有一句“卧槽”这类强词，合适的时候带一个正流行的梗；严肃题和商单不加，你不想要也可以直接说
- 稿子写好了嫌太空、太说教、像广告：只改句子，不动你的结构和判断
- 写产品文案、广告口播、获客视频（马师傅的卖点五问、情绪钩、爽点三招，编导的“讲渴望比讲痛点管用”）；只有你明确在带货或获客时才走这一套
- 深度稿先让你选择讲法、时长，以及是否融合爆款风格；AI 可以推荐，但最终由你决定

## 怎么装

最省事：把这个仓库的链接发给你的 AI，跟它说“帮我把这个 Skill 装上，照 INSTALL.md 装”。Claude Code、Codex、Cursor、Copilot、Gemini CLI、OpenCode 这些能装 Skill 的工具，一般都能自己装好。装完新开一个对话再用。

自己动手装、各工具放在哪个目录、没有 Skill 功能的工具怎么用，见 [INSTALL.md](INSTALL.md)。更口语的版本在 [小白使用说明.md](小白使用说明.md)。

整个文件夹是一个 Skill，入口是根目录的 `SKILL.md`。子目录里的 `MODULE.md` 都是它的模块，不用单独装。

## 怎么开始

装好以后直接说你的主题、给谁看、想要什么成品就行。它会推荐方向，选哪个、写成什么由你定。

第一次可以直接复制这句：

> 用最强师傅帮我处理下面的需求。按模块步骤推进，不要跳步；我已经给过的信息算对应步骤做完了，不要重复问。先给判断和推荐理由，最后让我来选：＿＿＿＿＿＿。

工具没认到它的话，在前面加一句“先读取 `zuiqiang-shifu-v3/SKILL.md` 和 `zuiqiang-shifu-v3/WORKFLOW_PROTOCOL.md`”。

想先看成品长什么样，翻 [examples/](examples/) 里的三份示范。

## 使用边界

- 它管内容判断和成稿质量；一条视频最后火不火，看发布后的数据。
- 需要引用新闻、数据或外部事实时，应先核对来源；材料不足时不编数字、人物动机或结果。
- 规则、参考文件和子模块互相配合，删除文件可能让某些能力失效。
- 不同品牌的 Agent 服从程度不一样，第一次用时按小白说明做一次小测试。
