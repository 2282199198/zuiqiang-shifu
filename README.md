## Claude Code 安装

### 一行命令

```
git clone https://github.com/2282199198/zuiqiang-shifu.git "%USERPROFILE%\.claude\skills\zuiqiang-shifu"
```

Mac 用户：把 `%USERPROFILE%` 换成 `~`

### 手动安装

1. 下载 → 解压
2. 把 `zuiqiang-shifu` 整个文件夹复制到 `.claude/skills/` 目录
3. 重启 Claude Code

详细步骤 → [安装指南](安装指南.md)
